# 山茶花期来信 · Camellia Letters

《山茶花期来信》中日双语宣传网站。中文版与日文版分别使用对应配音、字幕的 60 秒概念宣传片。

- 中文版：`/index.html`
- 日文版：`/ja/index.html`
- GitHub Pages：https://scott1743.github.io/camellia-letters/

## 本地预览

```bash
npm run dev
```

打开 http://localhost:7100/ 。也可以通过 `npm run dev -- --host 0.0.0.0 --port 7100` 指定监听地址和端口。

网站为无构建依赖的静态 HTML / CSS / JavaScript，可直接部署到 GitHub Pages。
